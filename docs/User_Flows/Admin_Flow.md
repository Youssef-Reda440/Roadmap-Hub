**A. Creator Approval**

```text
Admin Dashboard
       ↓
Creator Applications
       ↓
View Application
       ↓
Review
       ↓
Approve / Reject
```

**B. Roadmap Moderation**

```text
Admin Dashboard
       ↓
Pending Roadmaps
       ↓
View Roadmap
       ↓
Review Content
       ↓
Approve / Reject / Request Changes
       ↓
Published / Back to Creator
```

**C. Reports**

```text
Admin Dashboard
       ↓
Reports
       ↓
View Report
       ↓
Review Reported Content
       ↓
Take Action
       │
       ├── No Action
       ├── Remove Content
       └── Suspend User
       ↓
Resolve Report
```

**D. User Management**

```text
Admin Dashboard
       ↓
Users
       ↓
Search / Filter
       ↓
View User
       ↓
Manage Account
       │
       ├── Activate
       ├── Deactivate
       └── Change Role
```
