**A. Become a Creator**

```text
Learner
   ↓
Apply as Creator
   ↓
Application Submitted
   ↓
Pending
   ↓
Admin Review
   ↓
Approved
   ↓
Creator Dashboard

OR

Rejected
   ↓
Learner
```

**B. Create Roadmap**

```text
Creator Dashboard
       ↓
Create Roadmap
       ↓
Basic Information
       ↓
Add Stages
       ↓
Add Topics
       ↓
Add Resources
       ↓
Organize / Reorder
       ↓
Save as Draft
```

**C. Submit Roadmap**

```text
Draft
  ↓
Review Roadmap
  ↓
Submit
  ↓
Pending Review
  ↓
Admin
  ↓
Approve ─────→ Published
  │
  └── Reject ─→ Creator
```

**Need Editing Roadmap ?**

```text
Published
    ↓
Edit
    ↓
Submit Again
    ↓
Pending Review
```

**D. Creator Statistics**

```text
Creator Dashboard

Statistics

```
